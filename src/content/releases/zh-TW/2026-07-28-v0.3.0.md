---
title: 更快的辨識、隨時重用的歷史與完整耗時分析
---

Typeflux 0.3.0 是我們第一個正式的 GitHub Release。這個版本讓日常語音輸入更快、更穩定，並新增歷史重用、伺服器選擇與完整耗時分析，讓整個處理過程更容易掌握。

## 隨時找回並重用歷史內容

在任何應用程式中按下 `⌥⌘O`，即可開啟最近歷史。

- 使用鍵盤瀏覽最近 20 筆可重用記錄
- 按 Return 將選取的結果插入目前游標位置
- 不必開啟完整歷史頁面，即可複製結果或重新轉寫
- 新增清楚可見的操作選單，方便播放、下載、重試、匯出與刪除

## 更強、更可靠的即時語音辨識

Typeflux 0.3.0 增加更多辨識選擇，也讓輕聲說話與較長錄音更不容易遺失有效內容。

- 新增 Soniox V5 即時語音辨識，支援 60 多種語言
- 阿里雲預設升級為 Paraformer Realtime V2，並支援手動選擇模型
- 豆包 Resource ID 可直接在設定中修改
- 純聽寫可使用更精簡的 Typeflux Cloud 路徑，減少不必要的處理等待
- 長錄音會依照錄音長度動態調整處理逾時
- 最終辨識回報靜音時，如果即時預覽已有有效文字，會保留預覽結果而不是直接捨棄

## 本機模型下載更直觀

本機模型下載現在更容易理解，切換模型也更加安全。

- 模型卡片直接顯示下載百分比與已傳輸大小
- 可從選單列查看正在下載的模型與即時進度
- 下載完成、失敗與重試都有更清楚的提示
- 新模型下載成功前繼續使用目前模型，不會因下載失敗影響工作
- 新手引導、設定頁面與執行中的工作流程共享同一份下載狀態

## 自動選擇更快的伺服器

新增「伺服器」設定，可控制 Typeflux 使用的 API 與語音辨識路線。

- 使用「自動」模式優先選擇速度更快的可用位址
- 必要時手動指定 API 或語音辨識伺服器
- 一鍵測試所有可用節點
- 透過「快速、一般、較慢、無法使用」直觀看到連線狀態

## 完整記錄每一步耗時

歷史詳情新增完整處理時間軸，可以查看一次請求的時間究竟花在哪裡。

- 音訊儲存與語音辨識耗時
- WebSocket 連線及最終結果等待
- DNS、TCP、TLS、請求上傳與伺服器等待
- 大型語言模型首字回應、結果下載與解析
- 文字寫入及全流程總耗時
- 本次請求實際使用的 API、語音辨識與大型語言模型位址

## 新增繁簡文字轉換

繁體中文介面新增基於 OpenCC 的文字轉換功能。

- 簡體轉臺灣繁體
- 簡體轉通用繁體
- 簡體轉香港繁體
- 繁體轉簡體

歷史記錄會分別保留原始轉寫、人設改寫、文字轉換與最終輸出，方便回看文字在各個階段發生的變化。

## 文字寫入與雲端服務更可靠

Typeflux 現在可以更穩妥地處理文字寫入失敗、帳號狀態與雲端錯誤。

- 無法將文字寫入目標應用程式時，自動顯示結果視窗，避免內容無聲遺失
- 帳號頁新增雲端用量、免費額度與剩餘額度
- 只有服務端開放付費功能時才顯示訂閱入口
- 改善登入狀態與 Keychain 憑證儲存
- 額度與訂閱錯誤不再被誤判為網路故障，也不會錯誤切換辨識器
- 語音辨識與後續改寫會更一致地使用目前人設並保留原文語言
- 自訂大型語言模型預設抑制不需要的 Thinking 或 Reasoning 內容

## 更精緻的介面與互動

- 錄音膠囊與對話框可選擇 Liquid Glass 或經典樣式
- 改善 Studio 元件在深色模式下的顯示
- 改進設定頁面的響應式版面與視窗尺寸限制
- 改善帳號、語音模型與大型語言模型的新手設定流程
- 錄音提示會在適當時間自動隱藏，減少視覺干擾

這個版本還包含大量錄音、轉寫、模型路由、文字寫入、登入、更新與設定相關的穩定性改進。
