Typeflux 1.0.0 完成了從「語音輸入工具」到「開源免費 macOS 全能型 AI 效率助手」的全面蛻變——將超級搜尋框（啟動器）、能動手做事的 AI Agent、按住說話語音輸入、Paste 風格剪貼簿管理、長截圖與高畫質螢幕錄影、多引擎對照翻譯以及滑鼠操作圓環裝進同一個原生應用程式中。

## 從一個超級搜尋框（⌘Space）開始，完成所有事

- 按下 `⌘Space` 呼出啟動器（超級搜尋框），不必先想「該打開哪個軟體」：支援秒搜應用程式、切換或結束視窗，並可直接搜尋與跳轉至 Safari、Chrome、Arc、Edge、Dia 已開啟的瀏覽器分頁與書籤。
- 在 Apple 晶片的 Mac 上，支援完全在本機離線檢索 PDF、Word、Excel、PPT、Markdown 文件內的內文——就算只記得文件中的一句話，也能找回檔案並在側邊欄高亮預覽段落。
- 邊輸入邊顯示即時計算、折扣與進位換算結果；輸入 `>` 即可在內嵌懸浮終端機或獨立多分頁終端機視窗中執行持久化 Shell 工作階段。
- 內建豐富的日常小工具：行事曆、1 秒級更新的即時系統監控（CPU、記憶體、磁碟、網路與行程管理）、本機硬體配置報告、世界時鐘、快速建立系統備忘錄（`note`）與提醒事項（`remind`）、18 項系統控制指令，以及近 20 款開箱即用的工作流程（匯率換算 `fx`、時間戳記 `ts`、JSON 格式化、JWT 解析、Cron 表達式、子網路計算、QR Code `qr`、文字遮罩等）。

## 在同一個輸入框裡，直接喚醒能動手做事的 AI Agent

- 在搜尋框直接輸入問題或任務並按 `⌘↩`：簡單問題透過「快速回答（Quick Ask）」直接在搜尋框下方即時回覆，無須開啟新視窗；複雜任務可無縫展開為完整對話工作區，並自動帶上呼出前選取的文字、目前應用程式或螢幕截圖作為上下文。
- 不只會聊天，更能在你授權的範圍內真正動手執行：支援讀寫與整理本機授權資料夾、執行終端機指令與程式碼沙箱（支援即時預覽網頁與圖表成果）、在內建側邊欄瀏覽器中查資料與填寫表單，以及替你點擊與操作應用程式（Computer Use）。
- 支援從 GitHub 一鍵安裝 AI 技能（Skills）與連接本機/遠端 MCP 伺服器；提供「每步都問」「標準（讀取自動進行，修改與執行指令前先確認）」「全自動」三種權限模式。
- 少一個順手的小工具？直接在對話中告訴 AI，Agent 會自動用 Python、Node.js 或 Shell 撰寫工作流程、完成測試並儲存到超級搜尋框中以關鍵字呼叫，且原生相容 Alfred Script Filter 的 JSON 輸出格式。

## 四種外觀形態的 AI 語音輸入與原地改寫

- 按住語音快捷鍵（預設 `Fn`）自然說話，放開後文字即刻插入目前應用程式的游標位置；先選取一段文字再按住說話（如「再精簡一點」、「改成正式商務郵件語氣」、「翻譯成英文」），即可直接原地替換選取內容。
- 提供底部膠囊、隨聲音律動的光球、選單列頂角卡片、以及貼合 MacBook 瀏海的「動態島」四種外觀樣式；支援為不同快捷鍵或不同應用程式綁定專屬人設（Persona）與語氣。
- 既可透過 WhisperKit、SenseVoice、Qwen3-ASR、FunASR 在 Mac 本機完全離線執行（聲音不離開本機），也可使用支援 60 多種語言的雲端低延遲即時語音辨識。

## 卡片架與列表雙視圖剪貼簿管理

- 按 `⌥⌘O`（或在搜尋框輸入 `clip`）即可開啟剪貼簿歷史，支援在緊湊「列表」與螢幕底部橫向展開的「卡片架（Card Shelf）」兩種視圖間自由切換。
- 全面支援文字、連結、程式碼、圖片、PDF、音訊/影片（卡片內支援直接播放波形）與檔案，並在同一面板整合了所有「語音轉寫記錄」與獨立儲存的「常用片段（Snippets）」。
- 支援全文搜尋、依來源應用程式篩選、空白鍵快速預覽、`⌘P` 釘選重要內容、自訂歷史保留時間（1 天至永久），以及按 `⌘1–9` 快速貼上或 `⌘↩` 貼為純文字。

## 全能截圖、自動捲動長截圖、敏感資訊遮罩與螢幕錄影轉 GIF

- 支援區域截圖（附像素級放大鏡）、視窗截圖、全螢幕截圖、自動捲動拼接的長截圖，以及將截圖釘選在螢幕上（Pin）對照查看。
- 內建箭頭、形狀、步驟編號、馬賽克與背景美化工具，支援一鍵智慧去背，以及自動辨識並遮蓋圖片中的手機號碼等敏感資訊。
- 截圖後可一鍵擷取圖中文字（OCR）、原圖翻譯，或直接帶著截圖向 AI 提問。
- 螢幕錄影支援選擇區域、視窗或全螢幕，可同時錄製系統聲音、麥克風並疊加攝影機子母畫面；錄製完成後可直接在內建編輯器中裁切首尾片段，匯出為 MP4 影片或高畫質 GIF。

## 多引擎並排對照翻譯、單字本與滑鼠操作圓環

- 選取文字、擷取螢幕區域或在搜尋框輸入 `fy` 即可翻譯，支援將 macOS 本機離線翻譯（資料不離機）與多家 AI 及翻譯服務並排對照；查單字自動產生附英美發音、詞性釋義與雙語例句的單字卡，一鍵收藏至內建單字本。
- 當手握滑鼠不想移回鍵盤時，按住圓環快捷鍵（`⌃⌥Space`）即可在滑鼠游標旁展開最多 8 扇區的操作圓環，朝目標方向一劃放開即執行，並支援依目前使用中的應用程式自動切換專屬的圓環動作。
