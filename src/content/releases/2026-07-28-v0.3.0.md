Typeflux 0.3.0 is our first official GitHub release. It makes everyday voice input faster and more dependable, while giving you better ways to reuse results, choose cloud routes, and understand where processing time goes.

## Recent History, One Shortcut Away

Press `Option + Command + O` from any app to open your recent Typeflux history.

- Browse the latest 20 reusable results with the keyboard
- Press Return to insert the selected result at the current cursor
- Copy a result or retry transcription without opening the full history page
- Use the new visible action menu for playback, download, retry, export, and deletion

## Real-Time Recognition That Keeps Up

Typeflux 0.3.0 adds more recognition choices and makes difficult recordings less likely to lose useful text.

- New Soniox V5 real-time transcription with support for more than 60 languages
- AliCloud now defaults to Paraformer Realtime V2 and supports model selection
- Doubao Resource ID can be configured directly in Settings
- Pure dictation can use a lighter Typeflux Cloud path to reduce unnecessary processing
- Long recordings receive a processing timeout that scales with recording length
- When final recognition reports silence but live preview already has useful text, Typeflux keeps the preview instead of discarding it

## Local Models with Clear Download Progress

Local model downloads are now easier to understand and safer to switch.

- See per-model percentage and transferred size directly on each model card
- Follow active downloads from the menu bar
- Receive clear completion, failure, and retry feedback
- Keep using the current model until the new one has finished downloading successfully
- Share the same download state across onboarding, Settings, and the running workflow

## Automatically Choose a Faster Server

The new Servers settings let you control the API and speech-recognition routes used by Typeflux.

- Use Automatic mode to prefer the fastest available address
- Select an API or ASR server manually when needed
- Run a speed test across all available endpoints
- See latency marked as fast, average, slow, or unavailable

## See Where the Time Went

History details now include a complete processing timeline for each request.

- Audio saving and speech-recognition duration
- WebSocket connection and final-result wait time
- DNS, TCP, TLS, request upload, and server wait
- LLM time to first output, response download, and parsing
- Text insertion time and end-to-end duration
- The actual API, ASR, and LLM endpoints used by the request

## Chinese Text Transformation

The Traditional Chinese interface now includes OpenCC-based text transformation.

- Simplified to Traditional Chinese for Taiwan
- Simplified to general Traditional Chinese
- Simplified to Traditional Chinese for Hong Kong
- Traditional to Simplified Chinese

History preserves the raw transcript, Persona rewrite, transformation result, and final output as separate stages.

## More Reliable Output and Cloud Handling

Typeflux now handles insertion failures, account state, and cloud errors more predictably.

- If text cannot be inserted into the target app, the result is shown in a copy dialog instead of being silently lost
- Cloud usage, free allowance, and remaining credits are available from the Account page
- Subscription controls only appear when billing is available
- Login sessions and Keychain token handling are more reliable
- Billing and quota errors no longer trigger misleading network failover
- Persona and source-language handling is more consistent across transcription and rewriting
- Custom LLM providers suppress unwanted thinking or reasoning output

## A More Polished Interface

- Choose between Liquid Glass and Classic styles for the recording capsule and dialogs
- Improved dark-mode presentation across Studio components
- More responsive Settings layouts with safer window sizing
- Clearer onboarding for accounts, speech models, and language models
- Auto-hiding recording hints reduce visual distraction

This release also includes broad reliability improvements across recording, transcription, model routing, text insertion, authentication, updates, and settings.
