Typeflux 0.2.0 is a major update focused on **real-time transcription, a cleaner interface, stronger context understanding, and app-level AI configuration**. This release makes voice input faster, smoother, and better aligned with your everyday workflow.

## Real-Time Transcription for Faster Voice Input

This is the biggest improvement in this release.

Typeflux now processes audio in real time. Instead of waiting until a full recording is finished before transcription begins, Typeflux continuously processes your speech as you talk, significantly reducing the time it takes to get results.

You will notice:

- Faster results after recording
- Less waiting for longer voice input
- More immediate transcription feedback
- A smoother experience across local and cloud models

## Refreshed UI: Cleaner and More Comfortable

We redesigned and refined many of Typeflux’s core interfaces.

The recording overlay, Ask & Answer window, Persona picker, Settings, login window, menu bar, and onboarding flow have all been polished. The overall interface now feels lighter, cleaner, and easier to understand.

You will see:

- Clearer recording status
- Easier-to-follow processing feedback
- A more natural chat-style Ask & Answer experience
- Better-organized settings
- A more consistent and comfortable interface

## Stronger Context Understanding

Typeflux now has a better understanding of what you are working on.

Whether you are using Typeflux in a browser, editor, or regular text field, it can better use selected text, current input, and app context to generate results that fit the situation more accurately.

Useful for:

- Asking questions about selected text
- Polishing, rewriting, or translating current input
- Getting more relevant answers based on browser or editor context
- Preserving selected content and context when switching to Ask mode

## App-Level AI Configuration

You can now configure different AI behavior for different apps.

For example, Typeflux can use a more casual style in chat apps, a more formal tone in email clients, and a concise technical style in code editors. Different apps can have different Personas, vocabulary, and processing preferences.

You can use this to:

- Automatically switch Personas by app
- Disable specific Personas for certain apps
- Use different settings for different work scenarios
- Make Typeflux better match your personal workflow

## Improved Vocabulary Experience

The vocabulary feature is now better suited for names, project terms, product names, technical terms, and frequently used phrases.

This release improves vocabulary import, search, sorting, and management. Vocabulary entries now also provide more consistent help for transcription and rewriting.

## In-App Feedback

You can now submit feedback directly inside Typeflux, with support for image attachments.

This makes it easier to report issues, share suggestions, or include screenshots when explaining a specific situation.

## Better Hotkey Experience

We improved hotkey recording and display, added support for more trigger styles, and fixed several modifier-key related issues.

Hotkey setup is now clearer and more reliable.

## History and Export Improvements

History audio playback has been improved. When exporting history, you can now choose where to save the export file, making it easier to archive and manage your data.

## More Reliable Auto Updates

Typeflux’s auto-update flow is now safer and more reliable. Updates are downloaded, verified, and installed more consistently, reducing update failures and installation issues.

## Typeflux Cloud Improvements

We improved Typeflux Cloud connection handling, routing, and error messages. When network, service, or account-related issues occur, the messages are now easier to understand.

## Local Model and Compatibility Improvements

Local speech model performance and reliability have been improved. This release also improves Intel build support, making Typeflux more reliable across more Mac devices.

## Fixes and Stability

This release also fixes multiple issues related to recording, transcription, microphone switching, interface display, login, updates, and settings.
