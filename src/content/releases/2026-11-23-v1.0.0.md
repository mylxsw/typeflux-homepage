Typeflux 1.0.0 marks a major evolution from a voice input tool into an all-in-one, open-source AI productivity assistant for macOS—unifying a supercharged search bar (launcher), an actionable AI agent, hold-to-talk voice typing, clipboard history, scrolling screenshots and screen recording, multi-engine translation, and a pointer action Ring into one native app.

## Start from One Supercharged Search Bar

- Press `⌘Space` to open the launcher and search apps, switch or quit windows, and jump directly to open browser tabs and bookmarks across Safari, Chrome, Arc, Edge, and Dia.
- On Apple silicon Macs, index and search inside local PDFs, Word, Excel, PowerPoint, and Markdown files completely offline, with side-by-side passage previews.
- Do instant math, unit, and base conversions as you type, or prefix a command with `>` to run persistent shell sessions in an inline floating terminal or tabbed terminal window.
- Access built-in daily tools by keyword: calendar with schedule and holiday views, 1-second live system monitor (CPU, memory, disk, network, processes), hardware system report, world clock, Apple Notes (`note`) and Reminders (`remind`), 18 system commands, and nearly 20 ready-to-use workflows (`fx`, `ts`, `json`, `jwt`, `cron`, `subnet`, `qr`, `obfuscate`, and more).

## An Actionable AI Agent, Right in the Same Input Box

- Ask a question in the launcher and press `⌘Return` for an instant inline answer (Quick Ask) without opening a new window, or expand into the full Chat workspace with your selected text, active app, or screenshot attached as context.
- Beyond conversation, the agent can read and organize files in folders you authorize, run terminal commands and code sandboxes with live HTML/artifact previews, browse and fill forms in a built-in sidebar browser, and operate apps on your screen (Computer Use).
- Extend the agent by installing Skills from GitHub or connecting local and remote MCP servers, and choose between Strict (ask every step), Standard (read automatically, ask before changes), and Full Auto permission modes.
- Need a custom launcher tool? Describe what you want in chat and the agent will write, test, and save a Python, Node.js, or Shell workflow behind a keyword—natively compatible with Alfred Script Filter JSON output.

## Voice Typing and In-Place Editing across 4 Capsule Styles

- Hold your voice shortcut (`Fn` by default), speak naturally, and release to insert clean text at the cursor in any app; select existing text and speak an instruction ("make this shorter", "translate into English") to rewrite it in place.
- Choose from four voice capsule appearances—Bottom Capsule, pulsing Orb, Top-Corner Card, or the MacBook Notch Island—and bind per-app Personas so work emails, code editors, and casual chats each use the right tone.
- Run speech recognition 100% offline on your Mac with WhisperKit, SenseVoice, Qwen3-ASR, or FunASR, or use low-latency cloud recognition across 60+ languages.

## Paste-Style Clipboard History and Reusable Snippets

- Press `⌥⌘O` (or type `clip` in the launcher) to browse everything you copied, switching freely between a compact List View and a bottom horizontal Card Shelf.
- Search and preview text, links, code snippets, images, PDFs, audio/video (with inline waveform playback), and files, unified in one panel with your voice transcription history and pinned reusable Snippets.
- Filter by source app, pin important items, set retention from 1 day to forever, and paste immediately with `⌘1–9` or as plain text with `⌘Return`.

## Screenshots, Scrolling Captures, Auto-Redaction, and Screen Recording

- Capture a region (with a pixel-level magnifier), a window, the full screen, or an auto-scrolling long page stitched into a single image, and pin captures above your workspace for reference.
- Annotate with arrows, shapes, step numbers, mosaic, and background beautification, remove image backgrounds in one click, or automatically detect and redact sensitive information such as phone numbers.
- Extract text from any capture (OCR), translate text directly on the image, or send the screenshot straight to the AI agent.
- Record a region, window, or full screen with system audio, microphone, and an optional camera picture-in-picture overlay, then trim the recording inline and export to MP4 or high-quality GIF.

## Side-by-Side Translation, Word Book, and Pointer Action Ring

- Translate selected text, typed queries (`fy`), or captured screen regions while comparing on-device macOS offline translation alongside multiple AI and translation services; look up dictionary cards with UK/US pronunciation and examples, and save words to your built-in Word Book.
- Hold the Ring shortcut (`⌃⌥Space`) to open a radial menu of up to 8 actions right at your mouse pointer—flick toward an action and release to run it without moving your hand back to the keyboard, with automatic per-app action profiles.
