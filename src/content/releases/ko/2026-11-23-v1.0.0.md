Typeflux 1.0.0은 음성 입력 도구에서 오픈 소스 macOS 올인원 AI 생산성 어시스턴트로 완전히 새롭게 진화했습니다. 런처(슈퍼 검색창), 실제로 작업을 수행하는 AI 에이전트, 누른 채 말하는 음성 입력, 클립보드 기록, 스크롤 스크린샷과 화면 녹화, 다중 엔진 비교 번역, 포인터 위치의 액션 링을 하나의 네이티브 앱에 담았습니다.

## 하나의 검색창(⌘Space)에서 모든 작업을 시작

- `⌘Space`를 눌러 런처를 열고 앱 실행, 창 전환 및 종료는 물론 Safari, Chrome, Arc, Edge, Dia에서 열려 있는 브라우저 탭과 북마크로 바로 이동할 수 있습니다.
- Apple 실리콘 Mac에서는 로컬 PDF, Word, Excel, PowerPoint, Markdown 문서의 본문 내용을 완전 오프라인으로 검색하고 일치하는 문단을 미리 볼 수 있습니다.
- 입력하는 즉시 계산과 단위·진법 변환 결과를 확인하고, `>` 접두사를 입력해 인라인 플로팅 터미널이나 탭 터미널 창에서 지속형 셸 세션을 실행할 수 있습니다.
- 키워드로 다양한 일상 도구를 바로 실행할 수 있습니다: 일정과 휴일을 보여주는 캘린더, 1초 단위로 갱신되는 실시간 시스템 모니터(CPU, 메모리, 디스크, 네트워크, 프로세스), 시스템 사양 리포트, 세계 시계, Apple 메모(`note`) 및 미리 알림(`remind`), 18가지 시스템 제어 명령, 약 20종의 기본 제공 워크플로(환율 `fx`, 타임스탬프 `ts`, JSON 포맷, JWT 디코딩, Cron, 서브넷 계산, QR 코드 `qr`, 민감 정보 마스킹 등).

## 같은 입력창에서 바로 실행하는 행동형 AI 에이전트

- 런처에 질문이나 작업을 입력하고 `⌘Return`을 누르면, 간단한 질문은 새 창을 열지 않고 검색창 아래에서 즉시 답변(Quick Ask)하고, 복잡한 작업은 선택한 텍스트나 현재 앱, 스크린샷을 문맥으로 첨부한 채 전체 채팅 워크스페이스로 이어집니다.
- 대화를 넘어 허용한 폴더의 파일 읽기와 정리, 터미널 명령 및 코드 샌드박스 실행(실시간 HTML/결과물 미리보기 지원), 내장 사이드바 브라우저를 통한 웹 탐색과 폼 입력, 화면을 보고 앱을 조작하는 Computer Use까지 수행합니다.
- GitHub에서 에이전트 스킬(Skills)을 설치하거나 로컬·원격 MCP 서버를 연결할 수 있으며, 「매번 확인」「표준(읽기는 자동, 변경 및 명령 실행 전 확인)」「완전 자동」의 3가지 권한 모드를 선택할 수 있습니다.
- 필요한 런처 도구가 있다면 채팅으로 설명해 보세요. 에이전트가 Python, Node.js, Shell 워크플로를 직접 작성하고 테스트한 뒤 런처 키워드로 저장하며, Alfred Script Filter의 JSON 출력 형식과도 네이티브로 호환됩니다.

## 4가지 캡슐 스타일의 음성 입력과 즉시 고쳐 쓰기

- 음성 단축키(기본값 `Fn`)를 누른 채 자연스럽게 말하고 떼면 현재 앱의 커서 위치에 깔끔한 텍스트가 입력됩니다. 기존 텍스트를 선택한 뒤 "더 짧게 줄여 줘", "영어로 번역해 줘"처럼 말하면 그 자리에서 바로 고쳐 씁니다.
- 하단 캡슐, 소리에 반응하는 오브, 화면 모서리 카드, MacBook 노치에 맞춘 「노치 아일랜드」의 4가지 스타일을 제공하며, 앱마다 알맞은 말투와 지침(Persona)이 자동으로 전환되도록 설정할 수 있습니다.
- WhisperKit, SenseVoice, Qwen3-ASR, FunASR를 통해 Mac 로컬에서 100% 오프라인으로 음성 인식을 실행하거나 60개 이상의 언어를 지원하는 초저지연 클라우드 인식을 사용할 수 있습니다.

## 카드 선반과 목록 보기를 모두 지원하는 클립보드 기록

- `⌥⌘O`(또는 런처에서 `clip`)를 눌러 클립보드 기록을 열고, 간결한 「목록 보기」와 화면 하단에 펼쳐지는 Paste 스타일의 「카드 선반(Card Shelf)」 사이를 자유롭게 전환할 수 있습니다.
- 텍스트, 링크, 코드, 이미지, PDF, 오디오/비디오(카드 내 파형 재생 지원), 파일을 검색하고 미리 볼 수 있으며, 음성 전사 기록과 자주 쓰는 스니펫(Snippets)도 한 패널에서 함께 관리됩니다.
- 출처 앱별 필터링, 중요 항목 고정(`⌘P`), 1일부터 영구까지의 보관 기간 설정, `⌘1–9` 빠른 붙여넣기 및 `⌘Return` 일반 텍스트 붙여넣기를 지원합니다.

## 스크린샷, 자동 스크롤 긴 캡처, 민감 정보 자동 가리기 및 화면 녹화·GIF 내보내기

- 영역 캡처(픽셀 확대경 포함), 창 캡처, 전체 화면 캡처, 긴 페이지를 자동으로 이어 붙이는 스크롤 스크린샷, 화면 위에 띄워 두는 고정(Pin) 기능을 제공합니다.
- 화살표, 도형, 단계 번호, 모자이크, 배경 꾸미기는 물론 원클릭 배경 제거(누끼)와 전화번호 등 민감한 정보 자동 감지 및 가리기 기능을 내장했습니다.
- 캡처한 이미지에서 텍스트 추출(OCR), 이미지 위 번역, 또는 스크린샷을 첨부한 AI 질문을 한 번에 실행할 수 있습니다.
- 시스템 오디오, 마이크, 카메라 화면(PiP)을 함께 녹화한 뒤 내장 편집기에서 앞뒤 구간을 잘라 MP4 동영상이나 고화질 GIF로 내보낼 수 있습니다.

## 다중 엔진 나란히 비교 번역, 단어장 및 포인터 액션 링

- 선택한 텍스트, 화면 영역 또는 런처의 `fy` 키워드로 번역할 때 macOS 온디바이스 오프라인 번역과 여러 AI·번역 엔진의 결과를 나란히 비교할 수 있으며, 발음과 예문이 담긴 단어 카드를 내장 단어장(Word Book)에 저장할 수 있습니다.
- 마우스에서 손을 떼지 않고도 링 단축키(`⌃⌥Space`)를 누른 채 원하는 동작 방향으로 스와이프한 뒤 떼면 최대 8가지 동작을 즉시 실행할 수 있으며, 현재 사용 중인 앱에 따라 전용 동작 구성으로 자동 전환됩니다.
