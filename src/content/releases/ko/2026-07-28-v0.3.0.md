---
title: 더 빠른 인식, 다시 쓰는 기록, 전체 처리 시간 분석
---

Typeflux 0.3.0은 첫 번째 정식 GitHub Release입니다. 일상적인 음성 입력을 더 빠르고 안정적으로 만들고, 기록 재사용, 서버 선택, 전체 처리 시간 분석을 추가해 처리 과정을 더 쉽게 파악할 수 있습니다.

## 단축키로 최근 기록을 바로 재사용

어떤 앱에서든 `⌥⌘O`를 누르면 최근 기록을 열 수 있습니다.

- 키보드로 재사용 가능한 최근 기록 20개 탐색
- Return 키를 눌러 선택한 결과를 현재 커서 위치에 삽입
- 전체 기록 페이지를 열지 않고 복사하거나 다시 전사
- 새 작업 메뉴에서 재생, 다운로드, 재시도, 내보내기, 삭제 실행

## 더 강력하고 안정적인 실시간 음성 인식

Typeflux 0.3.0은 더 많은 인식 서비스를 지원하며, 작은 목소리나 긴 녹음에서도 유효한 텍스트를 잃을 가능성을 줄였습니다.

- 60개 이상의 언어를 지원하는 Soniox V5 실시간 음성 인식 추가
- AliCloud 기본 모델을 Paraformer Realtime V2로 업그레이드하고 모델 선택 지원
- 설정에서 Doubao Resource ID 변경 가능
- 일반 받아쓰기에서는 더 가벼운 Typeflux Cloud 경로를 사용해 불필요한 대기 감소
- 녹음 길이에 따라 긴 녹음의 처리 제한 시간을 동적으로 조정
- 최종 인식이 무음으로 판단해도 실시간 미리보기에 유효한 텍스트가 있으면 결과로 유지

## 로컬 모델 다운로드 진행 상황을 명확하게 표시

로컬 모델 다운로드 상태를 더 쉽게 이해할 수 있고, 모델 전환도 안전해졌습니다.

- 모델 카드에서 다운로드 백분율과 전송된 크기 확인
- 메뉴 막대에서 다운로드 중인 모델과 실시간 진행 상황 확인
- 완료, 실패, 재시도 상태를 명확하게 안내
- 새 모델 다운로드가 성공할 때까지 현재 모델을 계속 사용
- 온보딩, 설정, 실행 중인 워크플로에서 동일한 다운로드 상태 공유

## 더 빠른 서버 자동 선택

새로운 서버 설정에서 Typeflux가 사용하는 API와 음성 인식 경로를 관리할 수 있습니다.

- 자동 모드에서 사용 가능한 가장 빠른 주소를 우선 선택
- 필요할 때 API 또는 음성 인식 서버를 직접 지정
- 사용 가능한 모든 엔드포인트를 한 번에 속도 테스트
- 지연 상태를 빠름, 보통, 느림, 사용 불가로 표시

## 각 단계에 걸린 시간 확인

기록 상세 화면에 전체 처리 타임라인이 추가되어 시간이 어디에서 사용됐는지 확인할 수 있습니다.

- 오디오 저장 및 음성 인식 시간
- WebSocket 연결 및 최종 결과 대기 시간
- DNS, TCP, TLS, 요청 업로드 및 서버 응답 대기
- LLM 첫 출력, 응답 다운로드 및 파싱 시간
- 텍스트 삽입과 전체 처리 시간
- 실제 사용된 API, 음성 인식 및 LLM 주소

## 중국어 문자 변환

번체 중국어 화면에 OpenCC 기반 문자 변환 기능을 추가했습니다.

- 간체에서 대만 번체로 변환
- 간체에서 일반 번체로 변환
- 간체에서 홍콩 번체로 변환
- 번체에서 간체로 변환

기록에는 원본 전사, Persona 수정, 문자 변환, 최종 출력이 각각 별도 단계로 보존됩니다.

## 텍스트 삽입과 클라우드 처리 안정성 향상

텍스트 삽입 실패, 계정 상태, 클라우드 오류를 더 예측 가능하게 처리합니다.

- 대상 앱에 텍스트를 삽입하지 못하면 내용을 잃지 않도록 결과 창에 표시
- 계정 화면에 클라우드 사용량, 무료 할당량, 남은 크레딧 표시
- 결제 기능을 사용할 수 있을 때만 구독 기능 표시
- 로그인 세션 및 Keychain 인증 정보 저장 개선
- 크레딧과 구독 오류를 네트워크 장애로 잘못 처리하지 않도록 수정
- 음성 인식과 후속 수정에서 현재 Persona와 원문 언어를 더 일관되게 유지
- 사용자 지정 LLM에서 불필요한 Thinking 또는 Reasoning 출력 억제

## 더 세련된 화면과 상호작용

- 녹음 캡슐과 대화상자에서 Liquid Glass 또는 클래식 스타일 선택
- Studio 구성 요소의 다크 모드 표시 개선
- 설정 화면의 반응형 레이아웃과 창 크기 제한 개선
- 계정, 음성 모델, 언어 모델의 초기 설정 흐름 개선
- 녹음 안내를 적절한 시점에 자동으로 숨겨 시각적 방해 감소

이 버전에는 녹음, 전사, 모델 라우팅, 텍스트 삽입, 로그인, 업데이트 및 설정 전반에 걸친 다양한 안정성 개선도 포함되어 있습니다.
