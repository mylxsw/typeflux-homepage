---
title: 更快的识别、随时复用的历史与完整耗时分析
---

Typeflux 0.3.0 是我们的第一个正式 GitHub Release。这个版本让日常语音输入更快、更稳定，并新增了历史复用、服务器选择和完整耗时分析，让整个处理过程更容易掌控。

## 随时找回并复用历史内容

在任何应用中按下 `⌥⌘O`，即可打开最近历史。

- 使用键盘浏览最近 20 条可复用记录
- 按回车将选中的结果插入当前光标位置
- 无需打开完整历史页面，即可复制结果或重新转写
- 新增明确可见的操作菜单，方便播放、下载、重试、导出和删除

## 更强、更可靠的实时语音识别

Typeflux 0.3.0 增加了更多识别选择，也让安静说话和较长录音更不容易丢失有效内容。

- 新增 Soniox V5 实时语音识别，支持 60 多种语言
- 阿里云默认升级到 Paraformer Realtime V2，并支持手动选择模型
- 豆包 Resource ID 可以直接在设置中修改
- 纯听写可以使用更轻量的 Typeflux Cloud 路径，减少不必要的处理等待
- 长录音会根据录音时长动态调整处理超时
- 最终识别返回静音时，如果实时预览已有有效文字，会保留预览结果而不是直接丢弃

## 本地模型下载更直观

本地模型下载现在更容易理解，切换模型也更加安全。

- 模型卡片直接显示下载百分比和已传输大小
- 可以从菜单栏查看正在下载的模型和实时进度
- 下载完成、失败和重试都有更明确的提示
- 新模型下载成功前，继续使用当前模型，不会因为下载失败影响工作
- 新手引导、设置页面和运行中的工作流共享同一份下载状态

## 自动选择更快的服务器

新增“服务器”设置，可以控制 Typeflux 使用的 API 和语音识别线路。

- 使用“自动”模式优先选择速度更快的可用地址
- 必要时手动指定 API 或语音识别服务器
- 一键测试全部可用节点
- 通过“快速、一般、较慢、不可用”直观看到连接状态

## 完整记录每一步耗时

历史详情新增完整处理时间线，可以查看一次请求的时间究竟花在了哪里。

- 音频保存和语音识别耗时
- WebSocket 建连及最终结果等待
- DNS、TCP、TLS、请求上传和服务器等待
- 大语言模型首字响应、结果下载和解析
- 文本写入及全流程总耗时
- 本次请求实际使用的 API、语音识别和大语言模型地址

## 新增繁简文本转换

繁体中文界面新增基于 OpenCC 的文本转换功能。

- 简体转台湾繁体
- 简体转通用繁体
- 简体转香港繁体
- 繁体转简体

历史记录会分别保留原始转写、人设改写、文本转换和最终输出，方便回看文字在各个阶段发生的变化。

## 文本写入和云端服务更可靠

Typeflux 现在可以更稳妥地处理文本写入失败、账号状态和云端错误。

- 无法把文字写入目标应用时，自动显示结果窗口，避免内容静默丢失
- 账号页新增云端用量、免费额度和剩余额度
- 只有服务端开放付费功能时才显示订阅入口
- 优化登录状态和 Keychain 凭证保存
- 额度和订阅错误不再被误判为网络故障，也不会错误切换识别器
- 语音识别与后续改写会更一致地使用当前人设并保留原文语言
- 自定义大语言模型默认抑制不需要的 Thinking 或 Reasoning 内容

## 更精致的界面和交互

- 录音胶囊和对话框可以选择 Liquid Glass 或经典样式
- 优化 Studio 组件在深色模式下的显示
- 改进设置页面的响应式布局和窗口尺寸限制
- 优化账号、语音模型和大语言模型的新手配置流程
- 录音提示会在合适的时间自动隐藏，减少视觉干扰

这个版本还包含大量录音、转写、模型路由、文本写入、登录、更新和设置相关的稳定性改进。
