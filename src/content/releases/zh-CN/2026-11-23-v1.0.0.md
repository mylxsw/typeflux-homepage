Typeflux 1.0.0 完成了从“语音输入工具”到“开源免费 macOS 全能型 AI 效率助手”的全面蜕变——把超级搜索框（启动器）、能动手干活的 AI Agent、按住说话语音输入、Paste 风格剪贴板管理、长截图与高清录屏、多引擎对照翻译以及鼠标操作圆环装进了同一个原生应用中。

## 从一个超级搜索框（⌘Space）开始，做完所有事

- 按下 `⌘Space` 呼出启动器（超级搜索框），无需先纠结“该打开哪个软件”：支持拼音秒搜应用、切换或退出窗口，并可直接搜索和跳转到 Safari、Chrome、Arc、Edge、Dia 中已打开的浏览器标签页与书签。
- 在 Apple 芯片的 Mac 上，支持完全在本机离线检索 PDF、Word、Excel、PPT、Markdown 文档里的正文内容——哪怕只记得文档里的一句话，也能找回文件并在侧边栏高亮预览对应段落。
- 边输入边出即时计算、折扣与进制换算结果；输入 `>` 即可在搜索框内嵌的悬浮终端或独立多标签终端窗口中运行持久化 Shell 会话。
- 内置丰富的本土化与日常工具：支持查看带农历、二十四节气及法定节假日调休（休/班）的日历，查看 1 秒级刷新的实时系统监控（CPU、内存、磁盘、网络与进程管理）和本机配置报告，快速记录系统备忘录（`note`）与提醒事项（`remind`），执行 18 项系统控制命令，并自带近 20 款开箱即用的工具工作流（汇率换算 `fx`、时间戳 `ts`、JSON 格式化、JWT 解析、Cron 表达式、子网计算、二维码 `qr`、敏感词脱敏等）。

## 在同一个输入框里，直接唤醒能动手干活的 AI Agent

- 在搜索框里直接输入问题或任务并按 `⌘↩`：简单问题通过「快速回答（Quick Ask）」直接在搜索框下方秒回，无需打开新窗口；复杂任务可无缝展开为完整对话工作区，并自动带上呼出前选中的文字、当前应用或屏幕截图作为上下文。
- 不光能聊天，更能真正在 Mac 上动手执行任务：支持在授权文件夹内读写与归档文件、运行终端命令与代码沙箱（支持实时预览生成的网页与图表制品）、在内置侧边栏浏览器中查资料与填表单、以及替你点击和操作应用（Computer Use）。
- 支持从 GitHub 一键安装 AI 技能（Skills）与接入本地/远程 MCP 服务；提供「每步都问」「标准（读取自动进行，改动与执行命令前先确认）」「全自动」三档权限模式，安全边界完全由你掌控。
- 缺个顺手的小工具？直接在对话里告诉 AI 你的需求，AI 会自动用 Python、Node.js 或 Shell 编写工作流、完成测试并保存到超级搜索框中通过关键词调用，且原生兼容 Alfred Script Filter 的 JSON 输出格式。

## 四种形态的 AI 语音输入与原地改写

- 按住语音快捷键（默认 `Fn`）自然说话，松开后文字即刻输入到当前应用的光标处；先选中一段已有文字再按住说话（如“精简一点”、“改成正式的工作邮件语气”、“翻译成英文”），即可直接原地替换选区内容。
- 提供底部胶囊、随声音律动的光球、菜单栏顶角卡片、以及贴合 MacBook 刘海的「灵动岛」四种外观样式；支持为不同快捷键或不同应用绑定专属人设（Persona）与表达语气。
- 既可通过 WhisperKit、SenseVoice、Qwen3-ASR、FunASR 在 Mac 本机完全离线运行（声音不出本机），也可使用支持 60 多种语言的云端低延迟实时语音识别。

## 卡片架与列表双视图剪贴板管理

- 按 `⌥⌘O`（或在搜索框输入 `clip`）即可打开剪贴板历史，支持在紧凑「列表」与屏幕底部横向展开的「卡片架（Card Shelf）」两种视图间自由切换。
- 全面支持文本、链接、代码、图片、PDF、音视频（卡片内支持直接播放音频波形）和文件，并在同一面板内打通了所有的「语音转写记录」与单独保存的「常用片段（Snippets）」。
- 支持全文搜索、按来源应用筛选、空格快速预览、`⌘P` 固定重要内容、自定义历史保留时长（1 天至永久），以及按 `⌘1–9` 极速粘贴或 `⌘↩` 粘贴为纯文本。

## 全能截图、自动滚动长截图、敏感信息打码与录屏转 GIF

- 支持框选截图（带像素级放大镜）、窗口截图、全屏截图、自动滚动拼接的长截图，以及将截图钉在屏幕上（Pin）置顶对照。
- 内置箭头、形状、步骤编号、马赛克与背景美化工具，支持一键智能抠图去除背景，以及自动识别并遮盖图片中的手机号等敏感信息。
- 截完图可一键提取图中文字（OCR）、原图翻译，或直接带着截图向 AI 提问。
- 录屏支持选择区域、窗口或全屏，可同时录制系统声音、麦克风并叠加摄像头画中画；录制完成后可直接在内置编辑器中裁剪首尾片段，导出为 MP4 视频或高画质 GIF。

## 多引擎并排对照翻译、单词本与鼠标操作圆环

- 选中文字、截取屏幕区域或在搜索框输入 `fy` 即可翻译，支持将 macOS 本机离线翻译（不出本机）与多家 AI 及翻译服务并排对比；查单词自动生成带英美发音、词性释义和双语例句的单词卡，一键收藏至内置单词本。
- 当手握鼠标不想移回键盘时，按住圆环快捷键（`⌃⌥Space`）即可在鼠标指针旁展开最多 8 扇区的操作圆环，朝目标方向一划松开即执行，并支持根据当前所在应用自动切换专属的圆环动作。
