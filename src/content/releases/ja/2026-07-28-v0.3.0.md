---
title: より高速な認識、再利用できる履歴、詳細な処理時間分析
---

Typeflux 0.3.0 は、初めての正式な GitHub Release です。日常の音声入力をより高速で安定したものにし、履歴の再利用、サーバー選択、詳細な処理時間分析によって、処理全体を把握しやすくしました。

## ショートカットですぐに履歴を再利用

どのアプリからでも `⌥⌘O` を押すと、最近の履歴を開けます。

- キーボードで最近の再利用可能な履歴 20 件を参照
- Return キーで選択した結果を現在のカーソル位置に挿入
- 履歴ページを開かずにコピーや再文字起こしを実行
- 新しい操作メニューから再生、ダウンロード、再試行、書き出し、削除を実行

## より強力で安定したリアルタイム音声認識

Typeflux 0.3.0 では認識サービスの選択肢が増え、小さな声や長い録音でも有効なテキストを失いにくくなりました。

- 60 以上の言語に対応する Soniox V5 リアルタイム音声認識を追加
- AliCloud の既定モデルを Paraformer Realtime V2 に更新し、モデル選択にも対応
- Doubao の Resource ID を設定画面から変更可能
- 通常の音声入力では、より軽量な Typeflux Cloud 経路を利用して不要な待ち時間を削減
- 録音時間に応じて長い録音の処理タイムアウトを調整
- 最終認識が無音と判定しても、ライブプレビューに有効な文字があれば結果として保持

## ローカルモデルのダウンロード状況を明確に表示

ローカルモデルのダウンロードが分かりやすくなり、モデルの切り替えも安全になりました。

- モデルカードに進捗率と転送済みサイズを表示
- メニューバーからダウンロード中のモデルと進捗を確認
- 完了、失敗、再試行の状態を明確に通知
- 新しいモデルのダウンロードが成功するまで現在のモデルを継続使用
- オンボーディング、設定、実行中のワークフローで同じ進捗状態を共有

## より高速なサーバーを自動選択

新しい「サーバー」設定から、Typeflux が使用する API と音声認識の接続先を管理できます。

- 自動モードで利用可能な最速の接続先を優先
- 必要に応じて API または音声認識サーバーを手動指定
- 利用可能なすべての接続先を一括で速度テスト
- 遅延を「高速、標準、低速、利用不可」で表示

## 各処理にかかった時間を詳しく確認

履歴の詳細に処理タイムラインが追加され、時間がどこで消費されたか確認できるようになりました。

- 音声保存と音声認識の所要時間
- WebSocket 接続と最終結果の待ち時間
- DNS、TCP、TLS、リクエスト送信、サーバー応答待ち
- LLM の最初の出力、レスポンス受信、解析時間
- テキスト挿入時間と処理全体の所要時間
- 実際に使用した API、音声認識、LLM の接続先

## 中国語の文字変換

繁体字中国語の画面に、OpenCC を利用した文字変換を追加しました。

- 簡体字から台湾繁体字
- 簡体字から一般的な繁体字
- 簡体字から香港繁体字
- 繁体字から簡体字

履歴には、元の文字起こし、Persona による書き換え、文字変換、最終出力がそれぞれ保存されます。

## テキスト挿入とクラウド処理の信頼性を向上

テキスト挿入の失敗、アカウント状態、クラウドエラーをより適切に処理します。

- 対象アプリにテキストを挿入できない場合は、内容を失わず結果ウィンドウに表示
- アカウント画面にクラウド使用量、無料枠、残りクレジットを追加
- 課金機能が利用可能な場合にだけサブスクリプション操作を表示
- ログインセッションと Keychain 認証情報の保存を改善
- クレジットやサブスクリプションのエラーをネットワーク障害として誤処理しないよう修正
- 音声認識と書き換えで Persona と入力言語をより一貫して維持
- カスタム LLM で不要な Thinking または Reasoning 出力を抑制

## より洗練された画面と操作

- 録音カプセルとダイアログで Liquid Glass またはクラシックスタイルを選択可能
- Studio コンポーネントのダークモード表示を改善
- 設定画面のレスポンシブレイアウトとウィンドウサイズ制限を改善
- アカウント、音声モデル、言語モデルの初期設定を分かりやすく改善
- 録音ヒントを適切なタイミングで自動的に隠し、視覚的な負担を軽減

このリリースには、録音、文字起こし、モデルルーティング、テキスト挿入、ログイン、更新、設定に関する多数の安定性向上も含まれています。
