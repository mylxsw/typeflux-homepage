---
title: 音声入力ツールから Mac のオールインワン AI アシスタントへ：ランチャー、AI エージェント、音声入力、クリップボード履歴、スクロール截圖・画面収録、翻訳、アクションリングをひとつに統合
---

Typeflux 1.0.0 は、音声入力ツールからオープンソースの macOS 向けオールインワン AI アシスタントへと大きく進化しました。ランチャー（検索バー）、実際に作業をこなす AI エージェント、音声入力、クリップボード履歴、スクロールスクリーンショットと画面収録、複数エンジン比較翻訳、ポインタ位置のアクションリングをひとつのネイティブアプリに統合しています。

## ひとつの検索バー（⌘Space）からすべてを開始

- `⌘Space` でランチャーを呼び出し、アプリの起動やウィンドウの切り替え・終了、Safari・Chrome・Arc・Edge・Dia で開いているブラウザタブやブックマークへのジャンプをすぐに行えます。
- Apple シリコン搭載 Mac では、ローカルの PDF、Word、Excel、PowerPoint、Markdown 書類の本文を完全オフラインで検索し、該当箇所をサイドプレビューで確認できます。
- 入力と同時に計算や単位・進数変換の結果を表示します。先頭に `>` を付けると、ランチャー内のフローティングターミナルまたはタブ付きターミナルウィンドウで永続的なシェルセッションを実行できます。
- 日常ツールをキーワードで即座に呼び出せます：カレンダー、1 秒更新のシステムモニター（CPU・メモリ・ディスク・ネットワーク・プロセス）、システム構成レポート、ワールドクロック、Apple メモ（`note`）とリマインダー（`remind`）、18 種類のシステムコマンド、約 20 種類の組み込みワークフロー（為替 `fx`、タイムスタンプ `ts`、JSON 整形、JWT デコード、Cron、サブネット計算、QR コード `qr`、伏せ字化など）。

## 同じ入力欄から、実際に手を動かす AI エージェントを呼び出し

- ランチャーに質問やタスクを入力して `⌘Return` を押すと、短い質問はその場で即座に回答（Quick Ask）し、複雑な作業は選択中のテキストや現在のアプリ、スクリーンショットを文脈として引き継いだままチャットワークスペースへ展開します。
- 会話だけでなく、許可したフォルダ内のファイル読み書きや整理、ターミナルコマンドやコードサンドボックスの実行（HTML や成果物のライブプレビュー付き）、内蔵サイドバーブラウザでの調査やフォーム入力、画面上のアプリ操作（Computer Use）まで実行できます。
- GitHub からの Skills インストールや MCP サーバー接続に対応し、「毎回確認」「標準（読み取りは自動、変更やコマンド実行の前に確認）」「全自動」の 3 段階の権限モードを選べます。
- 自分用のツールが欲しいときは、チャットでやりたいことを伝えるだけで AI エージェントが Python・Node.js・Shell のワークフローを作成・テストしてランチャーに保存します（Alfred Script Filter の JSON 出力形式にネイティブ対応）。

## 4 種類のカプセルスタイルを選べる音声入力とその場での書き換え

- 音声ショートカット（既定は `Fn`）を押しながら話し、離すだけで現在のアプリのカーソル位置にテキストを入力します。テキストを選択してから「もっと短くして」「英語に翻訳して」と話すと、その場で書き換えます。
- ボトムカプセル、音に反応するオーブ、画面角のカード、MacBook のノッチに収まる「ノッチアイランド」の 4 スタイルから選べ、アプリごとに異なる Persona（文体や指示）を自動適用できます。
- WhisperKit、SenseVoice、Qwen3-ASR、FunASR による Mac 上での完全オフライン認識と、60 以上の言語に対応する低遅延クラウド認識の両方を利用できます。

## カードシェルフとリストを切り替えられるクリップボード履歴

- `⌥⌘O`（またはランチャーで `clip`）でクリップボード履歴を開き、コンパクトな「リスト表示」と画面下部に並ぶ Paste スタイルの「カードシェルフ」を自由に切り替えられます。
- テキスト、リンク、コード、画像、PDF、音声・動画（カード内での波形再生に対応）、ファイルを検索・プレビューでき、音声文字起こし履歴や定型文（スニペット）も同じパネルで扱えます。
- アプリ別の絞り込み、重要項目のピン留め、1 日〜無期限の保存期間設定、`⌘1–9` での即座の貼り付け、`⌘Return` でのプレーンテキスト貼り付けに対応しています。

## スクリーンショット、スクロール長尺キャプチャ、自動墨消し、画面収録・GIF 書き出し

- 範囲指定（ピクセル拡大鏡付き）、ウィンドウ、全画面、長いページを自動でつなぎ合わせるスクロールスクリーンショット、画面上に 고정するピン留め（Pin）に対応しています。
- 矢印、図形、手順番号、モザイク、背景装飾に加え、ワンクリックでの背景切り抜きや、電話番号などの機密情報の自動検出・墨消しを備えています。
- キャプチャした画像からの文字抽出（OCR）、画像上での翻訳、AI エージェントへの質問をワンクリックで行えます。
- システム音声、マイク、カメラのピクチャインピクチャを重ねた画面収録に対応し、収録後その場で前後をトリミングして MP4 または高品質な GIF に書き出せます。

## 複数エンジン並べて比較できる翻訳、単語帳、ポインタ位置のアクションリング

- 選択テキスト、画面範囲、またはランチャーの `fy` から翻訳でき、macOS のオンデバイスオフライン翻訳と複数の AI・翻訳サービスを並べて比較できます。発音や例文付きの単語カードを表示し、内蔵の単語帳（Word Book）に保存できます。
- マウスから手を離したくないときは、リングショートカット（`⌃⌥Space`）を押しながら使いたいアクションの方向へスワイプして離すだけで最大 8 個の操作を実行でき、現在のアプリに応じた専用アクションへの自動切り替えにも対応しています。
